# 05 — Job Application Strategy

## Job board priority

| Rank | Board | Lý do |
|---|---|---|
| 1 | [jobs.solana.com](https://jobs.solana.com) | Official, Solana-only, JD chất lượng |
| 2 | [web3.career](https://web3.career) | Salary disclosed nhiều, filter remote tốt |
| 3 | [cryptojobslist.com](https://cryptojobslist.com) | Volume cao, mix EVM/Solana |
| 4 | [Wellfound](https://wellfound.com) | Startup-heavy, equity-heavy roles |
| 5 | Remote3.co | Mid-tier; nhiều EU companies |
| 6 | LinkedIn | Spam nhiều, dùng để follow founders + recruiter |

**Twitter/X outbound**: hit rate ~5–15% reply. Tag founder của project bạn đã build on, kèm "I built X on your protocol, looking for a Solana engineer role".

## CV / GitHub README cho thị trường nước ngoài

**GitHub README ưu tiên**:
1. **Pinned 3 repo quality > 30 repo quantity**. Mỗi repo có:
   - Architecture diagram (mermaid OK)
   - Explorer link cho devnet/mainnet TX
   - Test coverage badge
   - "What I learned" section
2. **Profile README** ngắn: Rust + Solana, link to flagship project, contact
3. **Avoid**: tutorial-clone repo không có giá trị thật

**CV** (1 trang):
- Headline: "Rust/Solana Engineer | Backend → Web3"
- Section "Open Source / On-Chain": list 2–3 capstone với devnet link
- Section "Backend": current role, ngắn gọn
- KHÔNG list cert. Liệt kê **GitHub URL + 2 deployed program addresses**.

## Timeline thực tế (15–20h/tuần)

| Mốc | Trạng thái |
|---|---|
| M0–M6 | Học + build (KHÔNG apply) |
| M7 | Bắt đầu apply 5–10 jobs/tuần (junior–mid Solana, EU-friendly timezone) |
| M8–M10 | Phỏng vấn vòng đầu, fail nhiều, fix CV iteratively |
| **M11–M12** | **Offer đầu tiên** ($90–140K junior–mid remote-from-VN) |

→ **$5K/tháng đạt được M11–M12** với plan này. Aggressive nhưng realistic.

## Realistic salary cho remote-from-Vietnam contractor mid-level 2026

**$120–180K/năm USD** pre-tax. Net sau VN PIT (~5–35% bậc thang) + transfer fee ~70–80%.
