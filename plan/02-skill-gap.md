# 02 — Skill Gap Analysis

5 JD verbatim từ jobs.solana.com + web3.career. Pattern **mọi role** required:

1. **2+ năm Rust** systems-level
2. **1+ năm Solana program với Anchor** (production, không demo)
3. SPL/SVM/Account Model/PDA/CPI deep
4. RPC + off-chain indexing
5. Security mindset (reentrancy, overflow, rent exemption)

## Gap với background hiện tại (Backend + Blockchain cơ bản, Rust beginner-intermediate)

| Năng lực | Hiện tại | Yêu cầu | Gap | Effort fix |
|---|---|---|---|---|
| Rust ownership/lifetime/async | Beginner-Intermediate | 2+ năm production | Lớn | M1–2 |
| Anchor framework | Chưa | 1+ năm | Rất lớn | M3–4 |
| SVM/SPL/PDA/CPI | Chưa | Deep | Rất lớn | M3–5 |
| Async (Tokio) | Có thể có | Implicit yêu cầu | Trung bình | M2 |
| RPC/indexing | Backend kinh nghiệm | Solana-specific | Trung bình | M4 |
| **Production Solana program shipped** | **Không có** | **Bắt buộc** | **CRITICAL** | M3–6 |
| Personal brand + OSS | Không có | Real differentiator | Trung bình | M1–12 (parallel) |

→ **Critical gap = chưa có Solana program shipped on-chain**. Đây là điều **duy nhất** quyết định pass screen. Mọi gap khác secondary.
